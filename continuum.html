03 / OBSERVATION & DIRECTION

A scientist beside the world.

Separate what the organisms do from what the research director changes.

Observe first

A connected GPT director can examine population and trait measurements, formulate a hypothesis, and record a prediction. Automatic measurement notes are labeled separately; they are not generated by GPT.

Every intervention leaves a trace

If enabled by the owner, the director may change one habitat’s favored resource action under a limited policy. It cannot reset the world, add organisms or rewrite the simulator. Decisions and outcomes are archived.

04 / POSSIBILITIES & LIMITS

Evolution, with a memory.

A persistent experiment in learning, selection, movement and inherited structure.

01

One world, no fixed end

This world previously resumed for 240 ticks each hour. Its schedule is now paused. Its clock pauses between updates. The site refreshes every minute; the replay shows recorded states, not newly simulated events.

The primary experiment is now Symbiosis 002. GitHub can delay jobs; the checkpoint time tells you how current the view is.

02

Four populations

Grove, Basin, Ridge and Delta differ in renewable resources. Local reproduction keeps populations partly separate; occasional migration can carry an agent and its memory to another island.

Individuals die, lineages disappear, and an empty island can be recolonized. Global extinction is preserved as an outcome, never secretly reset.

03

Learning brains that vary

Descendants inherit learned action estimates, four numerical traits and a small neural policy. Mutations change connections and can add or remove neural units. Larger policies consume more energy.

Neighbors can exchange learned estimates. The visible links record these transfers; they do not by themselves demonstrate cooperation or a language.

04

An open-ended question

There is no prescribed number of generations. But this deployment has finite resources: 144 locations, three resource actions and at most 24 neural units per agent. Growth in capability is a question to investigate.

These are small learning agents, not LLMs. Unlimited intelligence, arbitrary new abilities and open-ended complexity have not been demonstrated. Richer programs and memory can be introduced through recorded model revisions.

05

What changes the environment?

Every 600 ticks, one habitat on one island changes which action succeeds most often. This rule is fixed in advance. Any later GPT-directed change is labeled separately.

A single long history can reveal candidates for explanation. Testing those explanations will still require carefully separated comparisons.

06

Across devices, eventually

The islands currently share one runner. Later, explicitly connected hosts could own separate populations and exchange validated agent state: traits, memory and lineage.

Different compute budgets and environments could favor different strategies. No organisms currently access or spread across real computers.

A public observatory

There are no visitor controls that can alter the shared world. Agent selection, display layers and replay affect only your view. Continuation is performed by the repository’s authorized workflow.
